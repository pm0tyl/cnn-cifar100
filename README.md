## Image Classification with CNN (CIFAR-100)

### Opis
Projekt przedstawia implementację konwolucyjnej sieci neuronowej (CNN) do klasyfikacji obrazów z datasetu CIFAR-100.

### Zakres
- przygotowanie i normalizacja danych
- budowa modelu CNN (Conv2D, MaxPooling, Dropout)
- trenowanie modelu
- ewaluacja (accuracy, precision, recall, confusion matrix)

### Technologie
- Python
- TensorFlow / Keras
- NumPy, Matplotlib

### Wyniki
Model osiąga dokładność ~42% na zbiorze testowym.  

### Cel projektu
Rozwijanie umiejętności w zakresie Machine Learning oraz analizy danych.
